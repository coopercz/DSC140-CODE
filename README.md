# DSC140-FINAL-ANALYSIS-CODE
This analysis is conducted in a Jupyter notebook. It explores a salary dataset within cybersecurity to see what factors help determine salary. The code starts with several imports for statistical analyses, data analyzing and visualization. After the introduction of the dataset, the assimilation of NA values and dropping them, the salary is explored based on three factors—remote ratio (amount of time people are allowed to work off site), experience level and company size. The salary correlation to each of these independent variables is determined by the Pearson method. The remote ratio does not need to be converted to numeric value, but experience and company size do—which this analysis provides. Bar graphs assess and display the results, as well as box plots. This is important for digital citizens to know because it provides credible research for anyone seeking to understand salaries based on remote potential, experience within cybersecurity and company size for where they might be employed or hiring them.
